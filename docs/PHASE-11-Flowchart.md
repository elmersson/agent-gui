# PHASE 11 — Per-Pane Agent Instances Flowchart

## Pane Creation Flow

```
┌─────────────────┐
│  User: :split-h │
└────────┬────────┘
         │
         ▼
┌─────────────────────┐
│  PaneManager.Split  │
└────────┬────────────┘
         │
         ├──────────────────────────────┐
         │                              │
         ▼                              ▼
┌─────────────────────┐    ┌─────────────────────────┐
│  Create new Pane    │    │  AgentRegistry.Create   │
│  in LayoutTree      │    │  Instance(newPaneID)    │
└─────────────────────┘    └────────────┬────────────┘
                                        │
                                        ▼
                           ┌─────────────────────────┐
                           │  NewInstance()          │
                           │  - New Adapter          │
                           │  - Empty History        │
                           │  - Default Model        │
                           └─────────────────────────┘
```

## Message Input Flow

```
┌─────────────────────┐
│  User types message │
│  and presses Enter  │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  Get focused pane   │
│  ID from PaneManager│
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  AgentRegistry.Get  │
│  Instance(paneID)   │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  Instance.Execute   │
│  (ctx, input)       │
└────────┬────────────┘
         │
         ├─────────────────────────────┐
         │                             │
         ▼                             ▼
┌─────────────────────┐   ┌─────────────────────────┐
│  Add to Instance    │   │  Call Adapter.Execute   │
│  History (user msg) │   │  with full history      │
└─────────────────────┘   └────────────┬────────────┘
                                       │
                                       ▼
                          ┌─────────────────────────┐
                          │  Stream response chunks │
                          │  via Event Bus          │
                          └────────────┬────────────┘
                                       │
                                       ▼
                          ┌─────────────────────────┐
                          │  Events include PaneID  │
                          │  for proper routing     │
                          └─────────────────────────┘
```

## Event Routing Flow

```
┌─────────────────────┐
│  Agent produces     │
│  OutputChunk event  │
│  with PaneID        │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  Event Bus delivers │
│  to TUI subscriber  │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  TUI checks         │
│  event.PaneID       │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  PaneManager.Get    │
│  Pane(paneID)       │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  Pane.AppendContent │
│  (chunk)            │
└─────────────────────┘
```

## Pane Close Flow

```
┌─────────────────────┐
│  User: :close-pane  │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│  Get focused pane   │
│  ID                 │
└────────┬────────────┘
         │
         ├──────────────────────────────┐
         │                              │
         ▼                              ▼
┌─────────────────────┐    ┌─────────────────────────┐
│  PaneManager.       │    │  AgentRegistry.Remove   │
│  ClosePane(id)      │    │  Instance(paneID)       │
└─────────────────────┘    └────────────┬────────────┘
                                        │
                                        ▼
                           ┌─────────────────────────┐
                           │  Instance.Stop()        │
                           │  - Cancel context       │
                           │  - Clear history        │
                           │  - Release resources    │
                           └─────────────────────────┘
```
